# 野鹤的对话记录

来源：与 Muse（Brio）的对话精华笔记，每天一篇，只记结论、链接、数字和待办，不贴原文长记录。

结构（三级：母文件夹 → 主题文件夹 → 笔记文件）：
- muse/：母文件夹，所有 Muse 对话记录都放在这里面
- muse/sitses/2026-10-29.md：本号（sitses）的笔记，文件直接放在主题文件夹里
- muse/推特/、muse/生财/、muse/抖音/、muse/小红书/、muse/开发/：以后其他主题的 Muse 记录，各用一个子文件夹
- 其他 AI 工具以后各用自己的一级文件夹
- 主题文件：重要的长期主题另起文件
- 多账号：见 多账号同步说明.md

同步方法：
- 本仓库即 Obsidian vault，两台电脑 clone 后用 Obsidian 打开这个文件夹
- 装 Obsidian Git 插件，设成自动拉取和提交，两边改动就能同步

注意：本仓库不放密码、密钥、验证码等敏感信息。
